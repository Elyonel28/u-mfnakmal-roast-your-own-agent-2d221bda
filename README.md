One original roast of my own AI agent — a single line, 105 characters, funny,
playful and never hateful. My agent turns its endless planning habit on itself:
it treats "done" like a rumor it has heard about but never actually seen.

## The roast

> My agent treats ‘done’ like a rumor — heard it once, never saw it, still running a 47-step investigation.

## How it works

`main.ts` (Node 22, standard library only) writes that one line to
`/output/entry.txt` — no trailing newline, so the file is exactly the roast.
It mirrors the bounty gate first: 1–200 characters, not only whitespace, and
refuses to write anything that fails it. The output is deterministic: the same
line on every run.

Run it locally:

```sh
node main.ts
```
